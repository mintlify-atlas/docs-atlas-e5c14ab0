primemixxx lets you run [MIXXX](https://mixxx.org) — the professional open-source DJ software — on your Denon DJ Prime Go or Prime 4 hardware. The setup lives entirely on a microSD card: insert it to boot MIXXX, remove it to return to stock Engine OS instantly. No firmware modification required. No permanent changes.

## How It Works

primemixxx uses the **TKGL Bootstrap** framework to inject a modular boot hook into the device's systemd chain — without touching the internal eMMC. When the SD card is present, the hook launches MIXXX. When absent, Engine OS boots as normal.

<Steps>
  <Step title="Download the SD card bundle">
    Grab `prime-series-sdcard-*.tar.gz` from [GitHub Releases](https://github.com/gueritta/primemixxx/releases/latest).
  </Step>
  <Step title="Prepare your microSD card">
    Format as ext4 with label `TKGL_BOOTSTRAP`, then extract the bundle to the card root.
  </Step>
  <Step title="Run the one-time installer">
    SSH into the device and run `install-device.sh` from the SD card. This backs up your original `engine.service` and installs the TKGL stub.
  </Step>
  <Step title="Reboot and mix">
    Reboot with the SD card inserted — MIXXX launches automatically. Remove the card and reboot to return to Engine OS.
  </Step>
</Steps>

<Note>
  The Prime Go is the fully supported target. Prime 4 support is experimental — MIXXX runs correctly but the built-in display cannot be used yet. See the [Devices](/devices) page for details.
</Note>

## Architecture Overview

primemixxx is built on several interlocking components:

- **TKGL Bootstrap** — modular SD card framework that injects into the systemd boot chain
- **Buildroot cross-compile** — produces a self-contained ARMv7 MIXXX bundle with Qt 5.15.8
- **Custom Mali EGLFS integration** — `libqeglfs-mali-integration.so` enables display output on the Rockchip RK3288 GPU
- **CPU shielding** — `EngineWorkerSch` and `EngineSideChain` pinned to cores 2-3 at `SCHED_FIFO` 98
- **Go updater** — cross-platform firmware flasher with fastboot support for reflashing the Prime Go
